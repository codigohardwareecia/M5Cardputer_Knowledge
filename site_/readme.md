
- Como instalar localmente o EasyMde

Acesse o link abaixo e cliquem em Salvar Como e cole na pasta script
https://cdn.jsdelivr.net/npm/easymde/dist/easymde.min.js

Faça o mesmo com outro link a e salve na pasta css
https://cdn.jsdelivr.net/npm/easymde/dist/easymde.min.css

Faá o mesmo com as fontes no link a seguir e salve como "font-awesome.min.css" na pasta css    
https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css

- Como instalar o jQuery localmente

Acesse o link abaixo e clique em Salvar Como e salve na pasta scripts 
https://code.jquery.com/jquery-3.7.1.min.js 

- Fonts
Faça o download das fontes em
https://fontawesome.com/v6/download

Extraia os arquivos e copie a pasta webfonts para raiz do projeto

- PDF
Para suportar a visualizacao de PDF acesse os links a seguir clique e Salvar Como e coloque na psta de scrips
https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.min.js
https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.worker.min.js
